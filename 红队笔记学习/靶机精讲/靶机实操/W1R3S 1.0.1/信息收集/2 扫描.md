端口扫描，详细信息扫描，UDP扫描，漏洞脚本扫描

```bash
sudo nmap -sT --min-rate 10000 -p- 10.10.10.21 -oA nmapscan/ports
```
	-sS S默认扫描技术，利用tcp syn标志位探测目标开放端口，发送syn包，收到回复即开放，收到复位即关闭 #快速
	-sT 发送完整tcp请求，收到syn，ack回复 #准确
	--min-rate 最最慢扫描发包速率 常用值：10000 #隐蔽
	-p-
		-p指定端口范围 
		-指定1-65535全部端口范围
	-oA 
		-o 输出
		A all输出格式
```bash
grep open nmapscan/ports.nmap | awk -F'/' '{print $1}' | paste -sd ','

ports=$(grep open nmapscan/ports.nmap | awk -F'/' '{print $1}' | paste -sd ',') #搜索端口数据行,并打印第一列,将输出结果重新排列为一行，以','分割 
```
	grep 搜索
	open 无意义，指定含有open的数据行
	| awk -F'/' '{print $1}' 不知道分别的意思，提取端口用
	paste -sd ','
		paste 重新排列
		-sd
			s 排列成行
			d 指定分隔符
	ports= 指定变量

```bash
sudo nmap -sT -sV -sC -O -p$ports ip -oA nmapscan/detail
#详细信息扫描
```
	-sT 指定以tcp协议扫描
	-sV 探测各服务版本
	-sC 用默认脚本进行扫描
	-O 探测操作系统的版本

```bash
 sudo nmap -sU --top-posts 20 10.10.10.21 -oA nmapscan/udp
 #UDP扫描 
```
	-sU 指定以udp协议扫描
	--top-posts 20 指定以常用的20个端口扫描

```bash
sudo nmap --script=vuln -p21,80,22,3306 10.10.10.21 -oA nmapscan/vuln
#默认脚本扫描
```
	--script=vuln 扫描nmap脚本目录的漏洞  vuln#漏洞
