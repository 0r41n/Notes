1、写字典
```bash
cewl http://dc-2 -w password.txt
```
	`cewl` (Custom Word List generator) 会爬取网页内容，提取关键词生成字典
    
	为什么不用通用字典？因为靶机作者在页面上提示了"用站点上的内容做密码"，这是靶机的考点
    
	生成的字典包含站点上的专有名词、常见词汇等

2、密码爆破
```bash
wpscan --url http://dc-2 -U user.txt -P password.txt
```
	将枚举到的用户名写入 `user.txt`
    
	`wpscan` 会用多线程尝试每个用户名+密码组合
    
	最终会拿到两组有效凭据：
    
	    jerry : [某个密码]
        
	    tom : [某个密码]

3、登录后台
浏览器访问 `http://dc-2/wp-admin`，用 jerry 的账号登录。

	 登录后台后可以翻找更多信息，可能发现 flag。但对最终 get shell 来说，SSH 才是主要入口。
