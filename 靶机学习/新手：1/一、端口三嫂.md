sudo nmap -p- 10.0.2.6 -oA ports  #全端口扫描/半开放扫描（只访问一次）
```
	-p- 全端口
	-oA 输出保存结果文件
	‘ports’文件名
```
sudo nmap -sU -F 10.0.2.6 -oA UDP #UDP扫描  （相当于舔狗跟女神说话）
```
	-sU 指定以UDP方式扫描
	-F 快速扫描（只扫前100频率最高的端口）
	UDP 单向端口
```
sudo nmap -p 21,80,55077 -sV -sC -sT -O 10.0.2.6 -oA details 
```
	-p 21,80,55077 指定21、80、55077端口
	-sV 详细服务扫描（版本）
	-sC 默认脚本扫描（扫描基础漏洞）
	-sT 指定以tcp扫描 (相当于跟ai说话句句有回应)
	-O 扫描目标系统信息
