	常用三扫
```bash
gobuster dir -u 'ip' -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x php,html,txt,zip,bak -t 50 -b 404
```
	gobuster 使用gobuster软件
	-w 指定字典路径
	-x * 指定要扫描的文件扩展名
	-t 50 线程数
	-b 404 隐藏404响应

	curl 访问网络地址/目标
```bash
ffuf -c -w /usr/share/wordlists/dirb/common.txt -u 'ip~FUZZ'
```
	-c 有颜色输出
	-w 指定字典
	-u 指定暴力破解目录
```bash
curl -L http://192.168.134.129/~secret/
```
	-L 自动跟随重定向
```bash
ffuf -c -w /usr/share/wordlists/dirb/common.txt -u 'http://192.168.134.129/.FUZZ' -e .txt,.html -fc 403#没扫出有用结果

ffuf -c -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -fc 404,403 -e .txt,.html -u http://192.168.134.129/~secret/.FUZZ.txt
#换字典尝试
```
	-fc 过滤指定的返回状态码
	-e 逗号分隔的扩展名列表。可以指定爆破的文件扩展名
```bash
curl http://192.168.134.129/~secret/.mysecret.txt
```
	.文件名 隐藏文件

```
|编码类型|字符集特征|示例|
|---|---|---|
|**Base64**|包含 `+`、`/`，末尾常有 `=`|`SGVsbG8gV29ybGQ=`|
|**Base58**|**无** `0`、`O`、`I`、`l`、`+`、`/`，无 `=`|你的这段文本|
|**Base32**|只有大写字母 `A-Z` 和数字 `2-7`，末尾有 `=`|`JBSWY3DPEBLW64TMMQ====`|
|**Base62**|只有 `0-9A-Za-z`，无特殊字符|`4E7jZ6fQ2p`|
|**Hex**|只有 `0-9` 和 `a-f`|`48656c6c6f`|
|**URL编码**|包含 `%`|`%48%65%6c%6c%6f`|
```
