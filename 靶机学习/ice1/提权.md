	`find`：Linux 里最强大的搜索工具。
    `/`：从系统的根目录开始，也就是搜遍整台电脑。
	`-perm -u=s`：这是核心！它的意思是寻找**带有 SUID 权限**的文件
	`-type f`：只找“文件（file）”，不找文件夹
	`2>/dev/null`：因为普通用户搜整个硬盘会遇到很多“权限不够”的报错（Permission denied），这个命令把所有的报错信息都扔进黑洞（`/dev/null`）里，让你的屏幕保持干净，只显示有用的结果。
	[为什么你一眼就盯上了 `/opt/get_access`？下面那些 `/usr/bin/sudo`、`/usr/bin/passwd` 都是 Linux 系统自带的正常程序，它们有 SUID 是理所当然的（否则你怎么改密码、用 sudo 呢）。在真实环境中，去攻击这些自带程序成功率极低。
    但是，**`/opt/get_access`** 这个名字太显眼了！
    `/opt` 目录通常是用来存放第三方软件或额外安装的程序的。
    名字叫 `get_access`（获取访问权限），这简直就是在向攻击者疯狂招手：“快来打我呀！”]

直接查看漏洞特征（验证判断）
```ssh
travis@debian:~$ strings /opt/get_access | grep -i "cat"
cat /root/system.info
```
	`strings` 是一个在 Linux 中用来**从一个“二进制文件”里提取出所有“人类能看懂的文本”**的工具。
	|:管道符（把前面的结果当成后面的输入）
	`grep`（搜索工具）：它负责在上一环节（`strings` 倒出来的一大堆废话里）寻找特定的文字。如果不加 `grep`，`strings /opt/get_access` 会给你刷出几百行乱七八糟的系统函数名和报错信息，你根本看不过来。
	`-i`（忽略大小写）：这是 `grep` 的参数，代表 ignore case（忽略大小写）如果不加 `-i`，你搜 `"cat"`，它就只会找完全匹配小写 `cat` 的行。如果程序里写的是 `Cat`、`CAT` 或者 `execCat`，它就搜不到。加上 `-i` 后，无论大小写怎么组合，它都能帮你揪出来。
	`"cat"`（你要找的关键词）：双引号里面的内容就是你的搜索词。为什么是 `cat`？因为你在找这个程序有没有调用 Linux 的读取文件命令 `cat`。

```bash
travis@debian:~$ echo -e '#!/bin/bash\n/bin/bash' > /tmp/cat
chmod +x /tmp/cat
-bash: /tmp/cat: Permission denied
chmod: changing permissions of '/tmp/cat': Operation not permitted
```
	`echo`：Linux 里的“大喇叭”，它的作用就是把后面的内容打印出来。
	
	`-e`：这是 `echo` 的一个参数，意思是“允许解释转义字符”。如果不加它，`\n` 就只是两个普通字符；加上它，`\n` 就会变成回车换行。
	
	`'#!/bin/bash\n/bin/bash'`：这是我们要打印的内容（用单引号包起来防解析）：
	    第一部分 `#!/bin/bash`：这叫 Shebang（释伴）。它的作用是告诉 Linux 系统：“当你看到这个文件时，请用 `/bin/bash` 这个解释器来运行我。”
		`\n`：换行符。
	    第二部分 `/bin/bash`：这是真正要执行的命令。它的作用就是由第一个shell的/bin/bash启动一个新的 shell（命令行）。
         `>`：重定向符。它的意思是“把左边打印出来的东西写进右边的文件里”。（注意：`>` 会覆盖原文件，如果原文件有东西会被清空）。
	    `/tmp/cat`：目标文件路径。为什么选 `/tmp`？因为 `/tmp` 是 Linux 的临时目录，所有用户（包括普通用户 travis）都有权限在里面创建、修改、执行文件。如果你选别的地方（比如 `/etc`），你连写的权限都没有。

环境变量劫持
```bash
travis@debian:~$ export PATH=/tmp:$PATH
```
	`export`：意思是“导出为全局环境变量”。它保证你修改后的 `PATH` 不仅对当前终端有效，还能传递给接下来由这个终端启动的任何子程序（包括 `get_access`）.
	`PATH`：这是一个极其重要的系统环境变量。它里面存了一串目录（用冒号隔开）。当你在终端敲 `cat`、`ls`、`ping` 时，系统会按照 `PATH` 里的目录顺序，一个一个去找这些命令。
    /tmp`：我们刚才存放“假 `cat`”的目录。
    `$PATH`：`$` 符号代表“引用变量”。`$PATH` 就是指原本那个长长的目录列表（通常是 `/usr/local/bin:/usr/bin:/bin` 等）。
    `:`：冒号是 Linux 里路径的分隔符。
**整句连起来的意思**：把 `/tmp` 这个目录，强行塞到原有系统路径列表的**最前面**。
