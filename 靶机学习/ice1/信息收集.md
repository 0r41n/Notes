- **`-h 192.168.65.129`**：`-h` 代表 host（主机），指定你要连接的远程数据库 IP 地址。

- **`--skip-ssl`**：**（核心排错点）** 之前你第一次连接时报了 `TLS/SSL error`。因为较新的 MySQL 客户端默认会尝试建立 SSL 加密连接，但靶机的数据库使用了自签名证书，验证不通过。加上 `--skip-ssl` 强制使用明文连接，完美绕过了这个报错。

- **`password` (varchar 64)**：**终极目标！** 长度是 64 个字符。这又是一个需要密码学常识的地方：
    
    - MD5 通常是 32 位。
        
    - SHA-256 是 64 位。
        
    - **Base64 编码**：非常常见，通常以 `==` 结尾。
