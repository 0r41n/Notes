使用规则
	?-前面是路径?后面跟参数
	"/'-参数后面接“破坏SQL结构
	-判断字段数：使用`order by`子句检测，从参数 `?nid=1 order 1`开始递增数字，直到报错，
	-判断回显位置：使用 `?nid=-1 union select 1`。将 `nid` 设为一个不存在的值（如 `-1`），是为了让页面无法显示正常内容，从而强制它显示你 `UNION SELECT` 注入的内容。观察页面，数字 `1` 出现的位置就是**回显位**。
		union：sql关键>把两条查询上下合并
		select 1：查询，返回一个字面量
	--+

查询特定ID内容
	?id=123#查询id为123的记录  id：通用编号，给任何东西的编号
	?nid=2#显示编号为2的节点内容    nid：文章、内容节点的编号
	?uid=admin#尝试改为admin能否越权   uid：用户的编号
	?cid=3    cid：分类编号、评论编号或内容编号
	?pid=55#查看55号商品或帖子   pid：商品编号、帖子编号或父级？编号
	?aid=2024#显示2024号文章   aid：文章编号，常见于新闻/博客系统
	?cid=electronics或?cid=3    分类编号或评论编号。电商中常见
